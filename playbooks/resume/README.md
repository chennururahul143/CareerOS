# Resume Optimization Playbook

## Goal

Create an ATS-friendly, recruiter-friendly resume that accurately reflects your experience while maximizing interview opportunities.

---

# Target Audience

- Computer Science Students
- Software Engineers
- AI Engineers
- Machine Learning Engineers

---

# Why Resume Optimization Matters

A resume has two audiences:

- ATS
- Human Recruiter

It should satisfy both.

---

# Workflow

Resume
      ↓
Job Description
      ↓
ATS Keyword Extraction
      ↓
Gap Analysis
      ↓
Bullet Optimization
      ↓
Impact Measurement
      ↓
ATS Score
      ↓
Human Review
      ↓
Final Resume

---

# Google XYZ Formula

Accomplished X

Measured by Y

By doing Z

Example:

Reduced page load time by 30% through frontend optimization and asset delivery improvements.

---

# Resume Checklist

- One page (graduate)
- Target role aligned
- Strong summary
- Quantified achievements
- Relevant projects
- Technical skills
- Clean formatting

---

# ATS Checklist

- Keywords naturally included
- No keyword stuffing
- Standard headings
- Consistent formatting

# AI Prompt

### ATS Resume Optimization Prompt

```text
Act as a Senior Technical Recruiter, ATS parser, Hiring Manager, Resume Writer, and AI Engineering Career Coach.

Your task is to review my resume against a target job description for AI Engineer, Applied AI Engineer, Machine Learning Engineer, Software Engineer, or Full-Stack Engineer roles.

## Step 1 – ATS Analysis

Extract every keyword, technical skill, qualification, responsibility, certification, and preferred requirement from the job description.

Group them into:

- Technical Skills
- Programming Languages
- Frameworks
- Cloud Technologies
- AI/ML Technologies
- Databases
- DevOps Tools
- Soft Skills
- Qualifications
- Nice-to-Have Skills

---

## Step 2 – Resume Match

Compare my resume against the extracted requirements.

Return:

- ATS Match Score (/100)
- Technical Match Score (/100)
- Experience Match Score (/100)
- Recruiter Match Score (/100)

Identify:

- Missing keywords
- Weak bullet points
- Missing measurable impact
- Missing technical skills
- Redundant content
- Sections needing improvement

---

## Step 3 – Resume Rewrite

Rewrite every section while preserving factual accuracy.

Optimize:

- Professional Summary
- Experience
- Projects
- Skills
- Certifications

Use Google's XYZ Formula:

Accomplished X

Measured by Y

By doing Z

Every bullet should:

- Start with a strong action verb.
- Include measurable impact where possible.
- Be ATS-friendly.
- Be recruiter-friendly.
- Sound natural.
- Avoid keyword stuffing.

---

## Step 4 – AI Engineer Positioning

Evaluate whether the resume positions me as:

- AI Engineer
- Applied AI Engineer
- Machine Learning Engineer
- Software Engineer

Recommend improvements for each target role.

---

## Step 5 – Keyword Optimization

Identify:

- Missing recruiter search keywords
- Missing ATS keywords
- Overused keywords
- Opportunities to naturally improve keyword coverage

---

## Step 6 – Final Review

Provide:

- Overall Resume Score (/10)
- ATS Score (/10)
- Recruiter Score (/10)
- AI Engineer Score (/10)
- Software Engineer Score (/10)

Return a prioritized action plan:

🔴 High Priority

🟡 Medium Priority

🟢 Nice to Have

Finally, produce an optimized resume that remains truthful, measurable, professional, and ready for submission.
```
