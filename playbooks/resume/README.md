# Resume Optimization Playbook

## Goal

Create an ATS-friendly, recruiter-friendly resume that accurately reflects your experience while maximizing interview opportunities.

---

# Target Audience

- Computer Science Students
- Software Engineers
- AI Engineers
- Machine Learning Engineers

---

# Why Resume Optimization Matters

A resume has two audiences:

- ATS
- Human Recruiter

It should satisfy both.

# Resume Checklist

- One page (graduate)
- Target role aligned
- Strong summary
- Quantified achievements
- Relevant projects
- Technical skills
- Clean formatting

---

# ATS Checklist

- Keywords naturally included
- No keyword stuffing
- Standard headings
- Consistent formatting
