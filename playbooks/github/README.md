# GitHub Optimization Playbook

## Goal

Build a professional GitHub profile that demonstrates engineering ability, project ownership, technical depth, and consistent development practices.

---

# Target Audience

- Computer Science Students
- Graduate Engineers
- Software Engineers
- AI Engineers
- Open Source Contributors

---

# Why GitHub Matters

GitHub is your engineering portfolio.

Recruiters and hiring managers use it to evaluate:

- Code quality
- Project complexity
- Documentation
- Commit history
- Engineering practices

---

# Workflow

```
Optimize Profile
        ↓
Pin Best Repositories
        ↓
Improve Documentation
        ↓
Organize Repository Structure
        ↓
Improve Commit History
        ↓
Add Screenshots
        ↓
Add Architecture
        ↓
Maintain Activity
```

---

# Step 1 — GitHub Profile

Complete:

- Professional profile photo
- Bio
- Location
- Portfolio
- LinkedIn
- Personal website

---

# Step 2 — Pinned Repositories

Pin your strongest projects.

Recommended order:

1. AI Intelligence Command Center
2. CareerOS
3. AI CS Portal
4. MeetMeHalfway
5. Research Repository
6. Portfolio

---

# Step 3 — Repository Standards

Every repository should contain:

- README
- LICENSE
- CONTRIBUTING
- .gitignore
- Roadmap
- Screenshots
- Architecture Diagram
- Installation Guide

---

# Step 4 — Documentation

Every README should include:

- Project Overview
- Problem Statement
- Features
- Architecture
- Tech Stack
- Installation
- Usage
- Roadmap
- Future Work

---

# Step 5 — Commit Quality

Use Conventional Commits.

Examples:

- feat:
- fix:
- docs:
- refactor:
- chore:
- test:

---

# Step 6 — Repository Quality

Review:

- Folder organization
- Naming conventions
- Code readability
- Documentation
- Issues
- Milestones

---

# Step 7 — Engineering Practices

Follow:

- SOLID principles
- Clean Architecture
- Feature-first structure
- Documentation-first development
- Versioning

---

# AI Prompt

## GitHub Repository Review Prompt

```text
Act as a Staff Software Engineer, Open Source Maintainer, and Technical Hiring Manager.

Review my GitHub profile and repositories.

Evaluate:

1. GitHub profile
2. Repository quality
3. Documentation
4. Folder structure
5. Architecture
6. Code quality
7. Commit history
8. Engineering practices
9. Maintainability
10. Recruiter impression

Provide scores (/10) for each category.

Identify weaknesses.

Suggest improvements.

Review each repository as if you were approving a production pull request.

Recommend which repositories should be pinned.

Finally generate a prioritized improvement roadmap.
```

# Checklist

- Profile completed
- Best repositories pinned
- README updated
- Documentation complete
- Architecture documented
- Conventional commits used
- Repository maintained

---

# Common Mistakes

- Empty repositories
- Missing README
- Poor commit messages
- No documentation
- Inactive projects
- Unclear architecture

- Professional GitHub profile
- Strong pinned repositories
- High-quality documentation
- Consistent engineering practices
- Recruiter-ready portfolio
